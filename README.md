## 📖 About the Repository

This repository contains C++ source code written for the **Advanced Data Structures (ADS)** practical coursework. It serves as a structured collection of core memory-management, data abstraction, and algorithmic problem-solving techniques ranging from linked structures to stack/queue operations and efficient searching/sorting methods.
